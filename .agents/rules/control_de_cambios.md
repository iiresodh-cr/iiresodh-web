# REGLA: APROBACIÓN PREVIA OBLIGATORIA DEL USUARIO

1. **NO TOMAR DECISIONES SIN APROBACIÓN DEL USUARIO:**
   - Queda terminantemente prohibido modificar estilos, colores, fuentes, componentes o comportamientos que no hayan sido expresamente solicitados por el usuario.
   - Cualquier sugerencia o propuesta de cambio colateral debe ser presentada al usuario y solo puede ejecutarse si este da su autorización explícita.

2. **MODIFICACIONES ESTRICTAMENTE PUNTUALES:**
   - Si el usuario pide modificar un elemento específico (por ejemplo, la imagen de fondo del Hero), únicamente se debe tocar ese elemento específico.
   - No alterar el color del título, los badges, las citas ni las tarjetas si el usuario no lo ha indicado.
